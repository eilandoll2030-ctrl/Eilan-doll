# قوائم «خلص» لكل مرحلة

كل مهمة تمر بهذي المراحل. ما تنتقل لمرحلة بعدها إلا إذا كل بنود المرحلة الحالية ✅.
المراحل في اللوحة (`tasks.status`): **جديدة → فهم → شغل → فحص → ينتظر المالكة → خلصت** (أو **متوقفة**).

---

## 1. جديدة → فهم
- [ ] المهمة لها قسم واحد مسؤول.
- [ ] الهدف مكتوب بجملة وحدة واضحة.
- [ ] موعد التسليم محدد (تاريخ + وقت بنظام 12 ساعة).
- [ ] مكتوب وش «الشكل النهائي» (ملف؟ رابط معاينة؟ مسودة؟).

## 2. فهم → شغل
- [ ] القسم قرأ الملفات/القرارات السابقة المتعلقة (الهوية، الأسعار، قرارات المالكة).
- [ ] لو فيه شي غامض، انسأل المدير التنفيذي (مو المالكة مباشرة).
- [ ] معروف هل المهمة تحتاج موافقة في الآخر (نشر/إرسال/صرف/إعدادات/كلمة سر).
- [ ] حدث «بدأ الشغل» مسجّل في `events`.

## 3. شغل → فحص
- [ ] الشغل مطابق للهدف والشكل النهائي.
- [ ] قائمة «خلص» الخاصة بالقسم (في `jd/`) كلها صح.
- [ ] الهوية المعتمدة: الشعار، الألوان، توقيع إيلان.
- [ ] العربي والإنجليزي سليمين.
- [ ] لا محتوى مخترع ولا محمي.
- [ ] الملفات محفوظة ومساراتها مكتوبة.

## 4. فحص → ينتظر المالكة
- [ ] قسم `qa` فحص وما لقى مشكلة عالية الخطورة.
- [ ] الملاحظات المتوسطة والبسيطة إما انصلحت أو مكتوبة.
- [ ] طلب في `needs` بصيغة: وش تشوف المالكة، وش القرار، خيارات الرد.
- [ ] الرابط/الملف يفتح من iPad.

> إذا المهمة ما تحتاج موافقة (مثل تقرير داخلي)، تنتقل من «فحص» إلى «خلصت» مباشرة.

## 5. ينتظر المالكة → خلصت
- [ ] المالكة ردّت على هذا الطلب بالذات (مو موافقة قديمة).
- [ ] نُفّذ بالضبط اللي وافقت عليه، ولا شي زيادة.
- [ ] `needs` انقفل بالرد والتاريخ.
- [ ] حدث «خلصت» في `events` + نقاط XP (حسب `levels.md`).
- [ ] تقرير خماسي مرفوع للمدير التنفيذي.

## متوقفة
- [ ] السبب مكتوب بسطر.
- [ ] وش اللي يفك التوقف (قرار؟ ملف؟ أداة؟).
- [ ] لو يحتاج المالكة: مسجّل في `needs`.
- [ ] المدير التنفيذي يراجع المتوقف في ختام كل يوم.

---

## قائمة خاصة: افتتاح 1 يناير 2027 (يتابعها `qa`)
- [ ] الصفحة الرئيسية والمقدمة (الشعار يبني نفسه) جاهزة ومدموجة.
- [ ] المتجر فيه منتجات حقيقية بأسعار معتمدة ودفع آمن **معتمد من المالكة**.
- [ ] منطقة الألعاب: «خمّن؟» مجانية، وكل لعبة مدفوعة لها فيديو شرح وعينة 3 بطاقات.
- [ ] إيلانتيوب يشتغل داخل الموقع.
- [ ] وجهتي و«أضف مشروعك» يشتغلون.
- [ ] حسابات السوشال جاهزة (تنشئها المالكة بنفسها).
- [ ] خطة محتوى الأسابيع الأخيرة قبل الافتتاح جاهزة.
- [ ] فحص كامل نهائي قبل الافتتاح بأسبوع.
