# الشعار النهائي — «عالمٌ يُبنى» / THE WORLD, BUILT

> **هذا هو الشعار المعتمد.** الموقع الحالي ما تغيّر فيه شي — ملفات الاستبدال جاهزة في
> `brand/final/` وتنتظر كلمة «بدّله».

---

## 1. الشعار

**كرة من مكعبات** (العالم — بنفس لغة مكعبات الشعار القديم) **فوق كتاب مفتوح** (المعرفة:
مدرسة/معهد/جامعة) **وفي قلبها مكعب بنفسجي** (العقل/الإنسان) **ومكعب ذهبي يطلع منها**
(النور/المستقبل) — مع مكعبتين خضراء تتوسطان، فتبقى الفكرة «مكعبات تبني عالم» كما هي.

معنى كل عنصر بسطر:

| العنصر | المعنى |
|---|---|
| كرة المكعبات | العالم — وهو **مبني** من لبنات، مو مرسوم |
| الكتاب المفتوح | المعرفة والتعليم — المدرسة والمعهد والجامعة |
| المكعب البنفسجي في القلب | العقل والإنسان — «عالم إنساني» |
| المكعب الذهبي الطالع | النور والخطوة نحو المستقبل |
| المكعبان الأخضران | البناء والطريق بين العالم والإنسان |

الشعار يشتغل على غامق وعلى كريمي، وله نسخة أيقونة، ونسخة لون واحد (للختم والطباعة).

## 2. الشعارات (Tagline)

**الأساسي:**
> مكعبات تبني عالماً — وعالم يبني إنساناً

**بدائل:**
- عالمٌ من مكعبات… وإنسانٌ من نور
- نبني عالماً رقمياً… ولا ننسى الإنسان
- كل مكعب لبنة. وكل لبنة عالم.
- من مكعب… إلى عالم. ومن عالم… إلى إنسان.
- أرقام تبني، وقلوب تسكن.

**نداء الافتتاح (Call to action):**
- «عالمك الرقمي… يفتح أبوابه»
- «ادخل عالمك»
- «من ١ يناير… لك عالم»
- «كون أول من يبني معنا»

## 3. الملفات

### `brand/final/` — الشعار نفسه
| الملف | الاستخدام |
|---|---|
| `mark.svg` / `mark-dark.svg` / `mark-light.svg` | الشعار الكامل (شفاف / على غامق / على كريمي) |
| `compact-*.svg` | نسخة الأيقونة (بدون كتاب) |
| `mark-orbit-dark.svg` | نسخة فيها مدار — للحملات والموشن |
| `mono-cream.svg` / `mono-ink.svg` / `mono-white.svg` | لون واحد: ختم، طباعة، حفر، فاكس |
| `lockup-h-*.svg` / `lockup-v-*.svg` | الشعار مع الاسم (أفقي/عمودي) |
| `png/favicon-{48,96,192,512}.png` | أيقونات المتصفح والتطبيق |
| `png/apple-touch-icon.png` | أيقونة iPad/iPhone |
| `png/og.png` | صورة المشاركة ١٢٠٠×٦٣٠ |
| `png/lockup-*.png`, `png/mark*.png` | تصديرات جاهزة للسوشال |
| `manifest.webmanifest` | ملف التطبيق (PWA) |

### `brand/launch/` — إعلان الافتتاح
| الملف | المقاس | الاستخدام |
|---|---|---|
| `launch-post-1080x1080.png` | ١٠٨٠×١٠٨٠ | بوست انستقرام/X |
| `launch-story-1080x1920.png` | ١٠٨٠×١٩٢٠ | ستوري/ريلز/تيك توك |
| `launch-banner-1500x500.png` | ١٥٠٠×٥٠٠ | غلاف X / لينكدإن / يوتيوب |
| `launch-wide-1200x630.png` | ١٢٠٠×٦٣٠ | مشاركة الروابط |
| `launch-presscard-1080.png` | ١٠٨٠×١٠٨٠ | كرت صحافة/تعريفي بالألوان |

كلها SVG + PNG — تعدّلين النص بفتح ملف `.svg` بأي محرر، أو تطلبين مني نسخة معدّلة.

## 4. قواعد الاستخدام

- **حد أدنى:** ٢٤ بكسل للأيقونة، ٦٤ بكسل للشعار الكامل.
- **مساحة حماية:** حول الشعار بمقدار مكعب واحد فارغ.
- **مكعب ذهبي واحد** في الشعار — لا أكثر. والبنفسجي **لمسة واحدة** (القلب فقط).
- على الفاتح استخدمي `-light`/`mono-ink`، وعلى الغامق `-dark`/`mono-cream`.
- لا تدوير، لا تمديد، لا ظل خارجي، ولا تغيير للنسب.
