> المالكة: صاحبة إيلان دول. تكلّم جلسة واحدة فقط: **المدير التنفيذي (CEO)**.
> كل الأوقات في هذه الملفات بنظام 12 ساعة، بتوقيت الرياض (UTC+3).

## 1. الفريق

| الرمز | القسم | الدور باختصار | الوصف الوظيفي |
|---|---|---|---|
| `ceo` | المدير التنفيذي | يستقبل أوامر المالكة، يوزّع المهام، يجمع التقارير، يدير خانة «ينتظرك» | [jd/ceo.md](jd/ceo.md) |
| `web` | قسم الموقع (التقنية) | تعديلات الموقع على GitHub، فرع المعاينة، لا دمج بدون «ادمجه» | [jd/web.md](jd/web.md) |
| `products` | المنتجات الرقمية | القوالب، ألعاب PDF، المخططات، منتجات التعلم البصري | [jd/products.md](jd/products.md) |
| `studio` | استوديو إيلان | موشن جرافيكس، فيديوهات AI، شروحات الألعاب، مقاطع الإعلانات | [jd/studio.md](jd/studio.md) |
| `marketing` | التسويق والسوشال | خطة محتوى الأسبوع، مسودات البوستات والإعلانات | [jd/marketing.md](jd/marketing.md) |
| `support` | خدمة العملاء والطلبات | فرز البريد وطلبات «أضف مشروعك»، مسودات الردود | [jd/support.md](jd/support.md) |
| `qa` | الجودة والافتتاح | فحص الموقع والمنتجات، الصدق في المحتوى، متابعة افتتاح 1 يناير 2027 | [jd/qa.md](jd/qa.md) |

كل قسم = جلسة Claude Code مستقلة. الأقسام لا تكلّم المالكة مباشرة؛ كل شيء يمر عبر المدير التنفيذي واللوحة.

### خط سير الشغل
```
المالكة ──أمر──▶ المدير التنفيذي ──مهمة──▶ القسم
                       ▲                     │
                       └──تقرير + اللوحة─────┘
     خانة «ينتظرك» ◀── كل ما يحتاج قرار المالكة
```

### من يسلّم لمن
- `studio` ← يأخذ الشعارات والهوية من `web`/الملفات المعتمدة، ويسلّم المقاطع لـ `marketing` ولـ `web` (شروحات الألعاب).
- `products` ← يسلّم المنتج لـ `qa` للفحص، ثم لـ `web` لإضافته للمتجر **بعد موافقة المالكة**.
- `marketing` ← يأخذ المقاطع من `studio` والمنتجات من `products`، ويسلّم مسودات فقط.
- `support` ← يرفع أي طلب فيه قرار أو فلوس إلى «ينتظرك».
- `qa` ← يفحص كل شيء قبل أن يُعرض على المالكة كـ «جاهز».

## 2. القواعد الثابتة (لا تُكسر)

### 2.1 ما يحتاج موافقة المالكة — كل مرة لحالها
أي عملية من هذي **ممنوعة** بدون موافقة صريحة من المالكة **على هذه العملية بالذات** (موافقة سابقة لا تُحسب لعملية جديدة):
1. **النشر**: دمج في الموقع الحي، نشر بوست، رفع منتج للمتجر، نشر Artifact لأي أحد.
2. **الإرسال**: أي إيميل أو رسالة أو رد لعميل أو أي جهة خارجية.
3. **الصرف أو الدفع**: اشتراك، شراء، خطة مدفوعة، تجربة مجانية تطلب بطاقة.
4. **تغيير الإعدادات**: إعدادات Vercel، GitHub، النطاق، الحسابات، المتغيرات البيئية.
5. **كلمات السر والمفاتيح**: إنشاء أو تغيير أو طلب أو تخزين أي كلمة سر أو مفتاح API.

> الطريقة: القسم يجهّز كل شيء حتى آخر خطوة، يضع طلبًا في **needs** على اللوحة، ويتوقف. المدير التنفيذي يعرضه على المالكة. لا تنفيذ إلا بعد ردها.

### 2.2 الأدوات والمهارات
- **لا يُثبَّت** أي مهارة (skill) أو أداة أو إضافة أو حزمة خارجية جديدة قبل عرض ملفاتها كاملة على المالكة وأخذ موافقتها.
- الأدوات المدفوعة: تُعرض مع السعر بالريال وبديل مجاني إن وجد.

### 2.3 الصدق والجودة
- لا تقييمات مخترعة، لا أرقام بدون مصدر، لا «عملاء» وهميين. كل شيء في إيلان حقيقي وواضح.
- كل منتج يحمل توقيع إيلان دول.
- لا نسخ أعمال محمية (شخصيات، شعارات، أغاني). أفكار أصلية فقط.
- الهوية المعتمدة: الشعار «مكعبات تبني عالم» (3×3 مكعبات، مكعب ذهبي مرفوع). الألوان: بنفسجي غامق (لمسة)، أخضر غامق، ذهبي، أسود، كريمي. لا تيفاني/نعناعي.
- عربي وإنجليزي، وصياغة عربية محايدة للجنسين في المنتجات.

### 2.4 الأوقات
- **نظام 12 ساعة دائمًا**: `7:30 ص`، `9:00 م`. لا تكتب 19:00 أبدًا في أي تقرير أو لوحة.

### 2.5 المالكة تستخدم iPad فقط
- أي خطوة مطلوبة منها تكون ممكنة من iPad، بخطوات بسيطة بدون مصطلحات.

```

✅ تم:
- ...

📁 الملفات:
- المسار أو الرابط — وصف بسطر

🟡 يحتاج المالك:
- [قرار/موافقة] ... (مسجّل في needs برقم: ...)

⛔ متوقف:
- ... — السبب — وش يفكّه

➡️ التالي:
- ...
```
- خانة فاضية تُكتب «لا شيء».
- المدير التنفيذي يدمج تقارير الأقسام في تقرير واحد للمالكة بنفس الصيغة.
